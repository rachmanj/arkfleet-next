App name: AccountingOne Support

MODULES:

- Departments: Sync with SAP B1
- Projects: Sync with SAP B1
- Bussiness Partner: Sync with SAP B1
- Loan Administration:
  - Loan creation
  - Loan installment schedule
  - Installment can be submitted to SAP B1 as AP Invoince
  - Installment payment can also be summited to SAP as Outgoing Payment
- Assets and Depreciation: 
  - Assets Recording
  - Assets Depreciation and Accumulated Depreciation List
  - Depreciation journal to SAP B1
- Bilyet Administration
  - 



STACKS: 

- Laravel
- Inertia.js
- React.js
- AntD
- MySQL
- (auth: Laravel session + Inertia; RBAC: Spatie recommended)


UI: 

- Dark/Light theme with default Dark, 
- sidebar menu,
- navbar menu with user's name on topright clickable to show dropdown menu and buttons to change password and logout,

- RBAC
